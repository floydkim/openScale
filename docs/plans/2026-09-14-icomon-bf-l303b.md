# ICOMON BF-L303B Support Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a narrowly matched, tested Kotlin GATT handler for the ICOMON BF-L303B (`Body scale` / `FI2019LB-B`) and prepare a focused branch for an upstream openScale pull request.

**Architecture:** Reuse the existing `ScaleDeviceHandler` transport and registry. Extract the existing WLA07 calculation from `ActiveEraBF06Handler` into one internal library, then let the new handler decode the ICOMON 20-byte `A2`/`A3` frames, send the observed `B1` profile, acknowledge `A0`/`A1`/`A3`, and publish a `ScaleMeasurement`.

**Tech Stack:** Kotlin, Android BLE through openScale's Blessed adapter, JUnit/Robolectric, Google Truth, Gradle.

## 4. Implement the ICOMON handler

File:

- Add `android_app/app/src/main/java/com/health/openscale/core/bluetooth/scales/IcomonBodyScaleHandler.kt`.

Implementation details:

- Match exact advertised name `Body scale` (case-insensitive) plus service `0xFFB0`.
- Declare and implement only `LIVE_WEIGHT_STREAM`, `BODY_COMPOSITION`, and `USER_SYNC`.
- In `onConnected`, reset session state, subscribe to `0xFFB2` and `0xFFB3`, send `B1` only when the user height is valid, and show the existing step-on hint.
- Parse only complete, checksum-valid 20-byte frames using the extracted protocol helper.
- Use `A2` state `0x03` as the stable-weight fallback and show progress for other positive weights.
- Use `A3` as the authoritative publication. Publish weight, optional non-zero heart rate, impedance, and WLA07 fields when profile and impedance are valid.
- Acknowledge only incoming `A0`, `A1`, and `A3` frames, matching the observed client behavior.
- If a stable `A2` was received but no `A3` arrived, publish a weight-only measurement on disconnect once; do not duplicate a published `A3`.
- Do not add history, time-sync, unit-change, battery, or generic `FFB0` behavior.

Run:

```sh
./gradlew testDebugUnitTest --tests '*IcomonBodyScale*'
```

Expected result: protocol, matching, and WLA07 tests pass.

Commit proposal: `feat: add ICOMON BF-L303B scale support`.
